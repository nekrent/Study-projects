# Агент для отбора стажировок на hh.ru

Агент собирает вакансии из двух автопоисков hh.ru в одну утреннюю подборку. Он отдаёт приоритет стажировкам по бизнес-анализу и для каждой позиции показывает, какие требования подтверждаются опытом кандидата.

Реализация — задача по расписанию в ChatGPT с подключённым Gmail. Правила отбора и профиль кандидата задаются в тексте задачи.

## Как это работает

1. Каждое утро агент проверяет письма автопоиска за предыдущий календарный день по Москве. Вакансии из разных писем объединяет по ID hh.ru.
2. Проверяет описание вакансии по прямой ссылке. Если страница недоступна, опирается на сведения из письма и отмечает, какие условия не удалось проверить.
3. Ставит стажировки по бизнес-анализу первыми. Если их меньше пяти, может добавить близкие junior-позиции с отдельной пометкой.
4. Сопоставляет обязанности и обязательные требования с профилем кандидата. Опыт, подтверждённый работой или проектом, получает больший вес.
5. Формирует подборку до пяти вакансий. Для каждой указывает компанию, прямую ссылку, город или формат работы, зарплату при наличии, 1–2 совпадения с профилем и существенное обязательное требование, которое пока не подтверждено, если такое есть.

## Как повторить настройку

1. Сохрани на hh.ru два поиска и включи доставку на почту. Первый — `бизнес аналитик` с типом занятости «Стажировка». Второй — `стажер бизнес аналитик` без фильтра по типу занятости. [Инструкция hh.ru по автопоиску](https://feedback.hh.ru/knowledge-base/article/1617).
2. Подключи к ChatGPT тот Gmail, на который приходят письма автопоисков.
3. Скопируй [шаблон задачи](task-prompt.md) и замени пример профиля сведениями из своего резюме. Достаточно указать навыки и примеры их применения.
4. Создай ежедневную задачу около 08:00 по Москве с этим текстом. [Инструкция по задачам ChatGPT](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt).

## Пример решения

В учебном примере оба автопоиска прислали одну стажировку. Компания ищет человека для описания процессов в BPMN и требует умения писать SQL-запросы с `JOIN`. В профиле кандидата есть учебный проект с BPMN, а практика SQL ограничена простыми выборками. Агент должен показать вакансию один раз, указать проект с BPMN и отметить, что работа с `JOIN` пока не подтверждена.
