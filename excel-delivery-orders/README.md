# Анализ сроков доставки в Excel

Учебный проект на синтетических данных магазина за октябрь 2026 года. Цель — сравнить, как часто три службы доставки привозят заказы позже обещанной даты.

[Открыть книгу Excel](excel-delivery-orders.xlsx)

1. Сопоставил выгрузки магазина и служб доставки по номеру заказа с помощью ВПР и проверил совпадения в обе стороны с помощью СЧЁТЕСЛИ.
2. Формулами посчитал дни просрочки и признак опоздания для доставленных заказов с обеими датами.
3. Собрал сводную таблицу и построил столбчатую диаграмму доли опозданий по службам.

В выборке опоздали **14 из 48** доставленных заказов (**29,2%**). Самая высокая доля у «Линии доставки» — **7 из 17** (**41,2%**). Заказы в пути и записи без пары учтены отдельно.
